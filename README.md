
## 🛠️ Installation & Setup

### Prerequisites
- Node.js (v16.x or higher)
- npm or yarn

### Steps to Run Locally

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```
   The app will be available at `http://localhost:5173`.

3. **Build for Production**:
   ```bash
   npm run build
   ```
   Optimized files will be generated in the `dist` folder.

## 📂 Project Structure

- `src/components`: Reusable UI components (Headers, Footers, SEO, etc.)
- `src/features`: Feature-specific logic and UI blocks (Home sections, About tabs)
- `src/pages`: Main page components
- `src/layouts`: Page layouts (Multipage, Default)
- `src/routes`: Route configurations using React Router
- `src/css`: Global and combined stylesheets
- `src/data`: Static data and configurations
